# Valorant BGM Player

一个给所有游戏玩家使用的 Windows 桌面 BGM 播放工具。

它不会读取游戏内存，不会修改游戏文件，也不会自动操作游戏。它只是一个后台音乐播放器，让你可以在游戏中用快捷键播放自己准备的胜利、失败或整活 BGM。

## 功能介绍

- 游戏内全局快捷键播放 BGM
- 本地音乐库管理
- 胜利、失败等分类播放
- 支持自定义快捷键
- 支持在线账号和在线音乐库
- 支持抖音音频提取
- 支持智能剪辑音频片段
- 内置 FFmpeg，无需用户单独安装
- 可选虚拟声卡，让队友也能听到 BGM
- 支持最小化到托盘后台运行

## 下载安装

从 Releases 页面下载最新版 Windows 安装包，然后双击安装。

首次启动时，Windows 可能会弹出管理员权限提示，请选择允许。

为什么需要管理员权限：

《无畏契约》等游戏可能在较高权限或特殊输入环境下运行。程序需要管理员权限，才能在游戏窗口处于前台时稳定接收快捷键。

## 默认快捷键

```text
Numpad1  播放胜利 BGM
Numpad2  播放失败 BGM
Numpad0  暂停播放
```

可以在程序左侧的“快捷键”页面修改。

建议优先使用小键盘按键，和游戏操作键冲突更少。

## 基本使用方法

1. 打开程序。
2. 进入本地 BGM 库。
3. 添加自己的音频文件。
4. 给歌曲选择分类，例如胜利或失败。
5. 进入游戏后，用快捷键播放对应 BGM。

关闭窗口后，程序会隐藏到系统托盘。如果想完全退出，请在托盘图标处退出程序。

## 在线功能

程序支持在线账号和在线音乐库。

如果你是普通用户，只需要登录账号即可使用。  
如果你是开发者或部署者，请在构建客户端时配置自己的 API 地址，不要把真实服务器地址写进 README 或源码。

构建时传入 API 地址示例：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-client.ps1 `
  -ApiBaseUrl "https://your-api.example.com/api" `
  -Installer
```

## 抖音音频提取

进入“工具”页面，粘贴抖音分享链接，即可尝试提取视频中的音频。

说明：

- 程序会自动启动本地解析服务。
- 本地解析服务只在你的电脑上运行。
- 如果启动失败，通常是被安全软件拦截，或旧版本安装包残留。

建议先退出旧版程序，再安装最新版。

## 智能剪辑

智能剪辑功能可以分析音频，并生成较短的 BGM 片段。

程序已经内置 FFmpeg，正常情况下不需要用户手动安装。

如果提示 FFmpeg 检测失败：

1. 确认使用的是最新版安装包。
2. 退出旧程序后重新安装。
3. 如果仍失败，尝试以管理员身份运行。

## 虚拟声卡

如果你希望队友也能听到 BGM，需要使用虚拟声卡，例如 VB-CABLE。

大致流程：

1. 安装虚拟声卡。
2. 在程序中选择对应的虚拟音频设备。
3. 在游戏语音设置里选择对应输入设备。
4. 测试队友是否能听到声音。

虚拟声卡配置和 Windows 音频设备有关，不同电脑可能略有差异。

## 常见问题

### 登录显示 Failed to fetch

一般是在线服务暂时无法连接，或客户端构建时配置的 API 地址不正确。

普通用户可以稍后重试。  
部署者需要检查后端服务是否正常运行。

### 游戏里快捷键没反应

可以按顺序检查：

1. 程序是否以管理员身份运行。
2. 是否使用最新版安装包。
3. 快捷键是否被其他软件占用。
4. 是否修改过快捷键但没有重启程序。

### 升级后 BGM 不见了

通常不是文件被删除，而是保存目录或配置路径变化。

可以在设置中重新选择 BGM 保存目录，然后重启程序。

### 抖音音频提取一直显示后端启动中

这是本地解析服务启动失败，不是云端账号服务问题。

可以尝试：

1. 退出程序和托盘图标。
2. 重新以管理员身份启动。
3. 检查安全软件是否拦截程序目录中的本地解析服务。
4. 使用最新版安装包重新安装。

## 开发说明

技术栈：

- 前端：React + TypeScript + Vite
- 桌面端：Tauri 2 + Rust
- 后端：Node.js + Express + MongoDB

安装依赖：

```powershell
npm install
```

前端构建：

```powershell
npm run build
```

桌面端构建：

```powershell
npm run tauri -- build
```

带 API 地址构建安装包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-client.ps1 `
  -ApiBaseUrl "https://your-api.example.com/api" `
  -Installer
```

## 项目结构

```text
valorant-bgm-player/
  src/                    前端页面和组件
  src-tauri/              Tauri/Rust 桌面端
  src-tauri/resources/    打包资源
  backend/                可选在线后端服务

```
